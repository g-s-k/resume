\section*{Experience}
\entry{Elektron Music Machines}{Gothenburg, Sweden}{Rust Audio Developer}{2022 -- present}
\begin{itemize}
  \item Built and released a new hardware instrument (\textit{Tonverk}) on a
    new development platform based on Rust and embedded Linux, then shipped
    four major OS updates within its first year on the market.
  \item Designed and implemented signature features of \textit{Tonverk}
    including the multi-sampled instrument format, \mbox{\textit{Subtracks}}
    machine, \textit{Auto Sampler}, and its track-routing system, drawing on my
    own experience as a musician and sound designer.
  \item Created audio effects for \textit{Tonverk} such as \textit{Degrader},
    \textit{Comb ± Filter}, and \textit{Frequency Warper}. These were built in
    C as part of a portable DSP library, intended to share code with other
    products.
  \item Designed and built the platform's USB device-mode framework, as a Rust
    application driving the Linux gadget configfs interface, allowing the
    exposed functions to be switched at runtime without a reboot. This supports
    Elektron's switchable UAC2 / Overbridge operation modes and will be used in
    future products.
\end{itemize}
